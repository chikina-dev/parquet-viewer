# Parquet Viewer (macOS)

Rust製のmacOS向けParquetファイルビューアーです。`eframe` (egui) と `polars` を使用して構築されています。

## 特徴

- **Parquetファイルの閲覧**: ローカルの `.parquet` ファイルを開いてテーブル形式でデータを閲覧できます。
- **高速な読み込み**: Polarsを使用しているため、大きなファイルでも比較的高速に読み込めます。
- **GeoParquet対応**: `geometry` カラムなどのWKB（バイナリ）データを検出し、自動的にWKT（テキスト）形式に変換して表示します。
- **日本語対応**: macOSのシステムフォント（ヒラギノ角ゴ）を自動的にロードするため、日本語を含むデータも文字化けせずに表示されます。
- **レスポンシブなUI**:
  - ウィンドウサイズに合わせてカラム幅が自動調整されます。
  - セル内のテキストが長い場合（WKTなど）は、セル内で横スクロールが可能です。

## 実行方法

Rustがインストールされている環境で、以下のコマンドを実行してください。

```sh
cargo run --release
```

初回ビルドには少し時間がかかる場合があります。

## 構成

- `src/main.rs`: エントリーポイント
- `src/app.rs`: アプリケーションのメインロジック
- `src/ui.rs`: テーブル描画とUIロジック
- `src/parquet_io.rs`: ファイル読み込み処理
- `src/fonts.rs`: フォント設定（日本語対応）
